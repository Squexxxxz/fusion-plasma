# FUSION PLASMA — complete static website

English: index.html. Hungarian: hu.html. Visitors choose EN / HU in navigation.
No installation, Node, build step, database, analytics, or external font service is required. All visible images are supplied real photographs. Original uploads are unchanged.

## Preview on your computer
1. Download and unzip the website package.
2. Open the fusion-plasma folder.
3. Double-click index.html to open English in your browser. Choose HU for Hungarian.
4. Make the window narrower to inspect the mobile layout. On a computer, phone links require a compatible calling application; on a phone they open the dialer. Email links use the visitor's configured mail application.

## Publish free with GitHub Pages
1. Create a free account at https://github.com if necessary.
2. Click +, then New repository. Name it fusion-plasma, choose Public, and create it.
3. Choose Add file → Upload files. Upload the CONTENTS of the fusion-plasma folder, including the assets folder. index.html must be at the repository root, not inside another fusion-plasma folder. Commit the upload.
4. Open repository Settings → Pages.
5. Under Build and deployment choose Deploy from a branch. Select main and /(root), then Save.
6. Wait for GitHub to show your published link. It normally looks like https://YOUR-USERNAME.github.io/fusion-plasma/.
7. Open both language versions on desktop and your phone. Check the phone and email links.

No website has been published by this delivery. These files are ready for GitHub Pages; no other hosting account is needed.

## Before publishing
- The user confirmed photo publication permission and identified the portrait as Emrah Tatar.
- The user confirmed the Budapest device is Fusion Plasma USA. Confirm the exact Fusion Plasma Pro model, model label, configuration, and offered accessories against the supplier documents. Do not assume every manufacturer model is identical.
- Obtain treatment dates, session counts, protocols, and consent documentation for the comparison photographs. The current site explicitly states that this context is missing, comparisons are not independently verified, and outcomes are not guaranteed. If those disclosures do not adequately reflect the seller's evidence, remove the case-images blocks before publication.
- Add the seller's legal/business name and any required local business disclosures once confirmed. No name, street address, credentials, representative status, or terms have been invented.
- Confirm current purchase terms directly. Pricing, stock, warranty, delivery, and training promises are deliberately absent.
- Ask for documentation supporting relevant Hungarian/EU use requirements and any patent or certification claim before adding one. This site makes no approval or efficacy claim.
- Have a Hungarian speaker review the translation in its final commercial context.
- Once the URL is known, optionally add og:url and a canonical URL to each page. Open Graph titles, descriptions, locale, and type are already present. No social image or fabricated URL was added.

## Editing
Edit text directly in index.html and hu.html. Keep both versions aligned. Colors, layout, and responsive rules are in styles.css. script.js controls only the accessible mobile menu. Photos have descriptive filenames and native dimensions, preserving comparison pairs without altering their contents.
